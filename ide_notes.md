# Git в VS Code vs терминал

## Что понравилось в VS Code

1. Наглядный diff по каждому файлу в панели Source Control — сразу видно, что именно изменилось, построчно, без чтения текстового вывода `git diff`.
2. Быстрые commit / push / pull прямо из интерфейса — для рутинных действий не нужно держать в голове точный синтаксис команд.
3. Расширение GitLens: показывает, кто и когда менял каждую строку файла (`git blame` в визуальном виде) — удобно разбираться в чужом или давно написанном коде.

## Что удобнее делать в терминале

- Сложные операции — interactive rebase, cherry-pick, работа с несколькими remote — удобнее в терминале: виден полный вывод команды и понятно, что именно произошло на каждом шаге, тогда как IDE местами скрывает эти детали за интерфейсом.
