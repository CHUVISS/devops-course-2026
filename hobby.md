# Мой amazing пет-проект

**Идея:** телеграм-бот для учёта личных расходов. Пишешь боту "кофе 250" или "зарплата +50000" — он сам распознаёт сумму, категорию и тип, сохраняет в базу. Команда `/stats` показывает сводку за неделю или месяц, `/last` — последние операции, `/limit 15000` — месячный лимит с предупреждением, `/export` — выгрузка в CSV.

**Стек:** Python 3.11, aiogram 3.x, SQLite + SQLAlchemy, pydantic, python-dotenv, Docker.

**Цель:** научиться писать асинхронный код на asyncio, проектировать схему БД и работать с ORM, парсить пользовательский ввод в свободной форме, деплоить бота на VPS с CI через GitHub Actions.

**План:** сначала хэндлеры `/start` и `/help` — просто чтобы бот отвечал. Потом парсер строки и запись в SQLite. Дальше `/stats`, `/last`, `/export`. Потом лимиты и уведомления. В конце Docker и деплой на VPS, чтобы работал 24/7.

**Итог:** рабочий бот, которым пользуюсь каждый день, и репозиторий на GitHub с нормальным README — первый проект в портфолио.
