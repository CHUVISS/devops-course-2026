# Мои цели на семестр

1. **Уверенно работать с Git и GitHub** — освоить не только базовые `add` / `commit` / `push`, но и rebase, squash, разрешение конфликтов и работу с несколькими remote, чтобы применять это в реальных проектах, а не только на занятиях.
2. **Разобраться в Docker и CI/CD** — научиться паковать свои pet-проекты (например, телеграм-бота для учёта расходов) в контейнеры и настраивать автоматический деплой через GitHub Actions.
3. **Довести пет-проект до рабочего состояния** — используя знания из курса, задеплоить телеграм-бота на VPS так, чтобы он работал постоянно, а не только во время разработки.
